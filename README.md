# Project source packages

These starter projects match the three new portfolio cards.

| Project | Run it |
| --- | --- |
| Web Scraper + Data Dashboard | `pip install -r web-scraper-dashboard/requirements.txt`, then `streamlit run web-scraper-dashboard/app.py` |
| AI Study Assistant | Set `GEMINI_API_KEY`; `pip install -r ai-study-assistant/requirements.txt`; then `uvicorn app:app --reload` from `ai-study-assistant` |
| Expense Tracker | Run `python expense-tracker/app.py` |
